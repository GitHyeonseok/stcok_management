## 수정 내용
- OFF 리밸런싱 총액에서 RP를 중복/가상 계산하지 않습니다. OFF 총액은 코어 보유액 + 전체 RP + 선택한 예수금/현금/신규자금입니다. 기존 30% 전략 대기목표를 확보한 나머지만 매수합니다. ON 총액은 코어 보유액 + 선택 투입금입니다.
- 전체 리밸런싱도 정수 수량으로 실제 예상 비중/잔액을 계산합니다. 평가금액만 저장된 앱이므로 매도수량은 추정이며, 전량매도 수량은 증권사 실제 보유수량으로 확인해야 합니다.
- 시세/환율 누락, 직전 확정 월봉 누락, 갱신 후 96시간 초과 시 주문 안내를 보류합니다. 96시간은 단순 신선도 기준으로 거래소 휴장일을 정밀 판정하지 않습니다.
- QQQ 기준 가격을 업데이트 스크립트 내에서 하나로 통일합니다. 필수 데이터 수집 실패 시 기존 data.json을 보존하고 작업을 실패 처리합니다.
- AI 자유문장 정규식 추출을 없애고 JSON 요청·검증, 최대 1회 재시도를 사용합니다. JSON 스키마를 모델 차원에서 강제한다는 뜻은 아닙니다.
- 모르는 이름/금액은 삭제하지 않고 확인 항목으로 유지합니다. 서버 경고와 응답 원문을 볼 수 있습니다. QLD 2배와 한글 템퍼스 이름을 보정합니다.
- 사용자 확인 체크, 반영 전후 금액 확인, 동일 종목 중복 선택 방지, 같은 사진 재합산 방지, 반영 직전 자동백업을 추가했습니다. 파일 내용이 달라진 사진은 동일 사진으로 판정되지 않을 수 있습니다.
- 원금 0일 때 전액을 이익으로 표시하지 않습니다. 현재 보유자산 취득원가를 입력한 경우만 평가손익을 표시합니다. 기존 누적 원금이 누적 입금액이라면 취득원가로 바꿔야 합니다. 입출금·실현손익·현금·배당 재투자 기록이 없는 총수익률은 계산 보류로 표시합니다.
- 한국 날짜로 매매일/백업일/순자산 기록일을 정합니다. 금액이 같다는 이유만으로 기타자산을 자동 삭제하던 이전 마이그레이션을 제거했습니다.

매매규칙 자체는 업데이트하지 않았습니다. QLD 30%와 기존 월봉 HA 기준을 그대로 유지합니다. BTC/168거래일 비상규칙 추가는 포함하지 않습니다.

## 검증
실제 제공된 HTML JavaScript를 Node VM에서 실행하고 Worker의 AI 바인딩을 모의 응답으로 교체해 검증했습니다.
- 15개 테스트 그룹 통과. 이 중 500개 서로 다른 포트폴리오로 현금 보존, 음수 잔액 방지, OFF 대기금 보존 검증.
- 700만 원 코어 + 300만 원 RP에서 총액 1,000만 원/대기금 300만 원 확인.
- 전 종목 주문 0주인 경우 비중이 가짜로 변하지 않음 확인.
- 스크린샷 8개 항목을 사람이 판독해 만든 응답의 분류/금액 파싱 확인. 실제 AI가 사진을 정확히 판독했다는 테스트는 아닙니다.
- JSON 오류 재시도, 두 번 실패 시 중단, 미분류/외화/잘못된 금액 보존, 중복/재합산 차단, RP 보존, 반영 전 백업 확인.
- Python 코드 문법 검사 및 제공자 모의 데이터로 수집 실패 시 원본 보존, 성공 시 원자적 교체, QQQ 가격 일치 검증.

## 미검증 및 한계
원격 브라우저에서 수정본을 열려고 했지만 작업 서버 연결 실패와 로컬 파일 URL 보안 차단으로 수정본의 실제 렌더링/모바일 터치 검증은 완료하지 못했습니다. 실제 Cloudflare 계정의 AI 호출, GitHub Actions 실행, 외부 시세 수집도 실행하지 않았습니다. 기존 공개 사이트는 앞서 직접 열어 확인했으나 수정본 배포는 하지 않았습니다.

OCR 결과는 여전히 틀릴 수 있어 사진과 대조해야 합니다. AI가 보고한 항목 수도 정확성 보장이 아닙니다. 주문 금액은 수수료·세금·환전 스프레드를 포함하지 않는 추정입니다. 평가금액은 스크린샷/수동 입력 시점의 값이며 자동 시세 갱신으로 보유평가액 자체가 실시간 갱신되지는 않습니다. 자동백업은 같은 브라우저의 이전 상태 1개이므로 기기 분실 대비 JSON 파일 백업이 필요합니다.
